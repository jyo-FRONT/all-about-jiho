## Deploy workflow

This repo is connected to GitHub (`jyo-FRONT/all-about-jiho`) and Vercel auto-deploys on every push to `main`. After making any content or code change the user asks for, always commit and push it yourself (`git add -A && git commit -m "..." && git push`) so the live site (https://all-about-jiho.vercel.app) stays in sync — don't wait to be asked. Git identity and GitHub credentials are already configured on this machine, so no login step is needed.
